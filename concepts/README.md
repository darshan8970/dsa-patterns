# Concept Problems

Problems in this folder are **not from LeetCode**. I write these myself, usually right after
learning a new concept, to test whether I actually understand it or just followed a tutorial.
The bar for a concept problem: I should be able to explain *why* it's testing what it's testing,
not just what it outputs.

## Format

Each concept gets its own folder:

```
concepts/
└── nnn-topic-name/
    ├── README.md      # the concept, why I wrote this problem, and what it's testing
    └── solution.py     # (or .ipynb for anything data/ML-adjacent)
```
